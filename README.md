# 📊 Interactive Sales Analytics Dashboard

A dynamic Power BI dashboard designed to analyze sales trends and customer behavior. This solution streamlines reporting, improves data-driven decision-making, and enhances overall data quality.

---

## 🔧 Features

- Interactive visualizations for key sales and customer insights  
- Automated data refresh and reporting  
- Advanced calculations using **DAX**  
- Data transformation and cleaning with **Power Query**  
- Drill-down capabilities for deeper analysis  

---

## 📈 Impact

- ✅ Improved decision-making by **20%**  
- ✅ Reduced manual reporting time by **35%**  
- ✅ Increased data accuracy by **25%**

---

## 🛠️ Tech Stack

- **Power BI**  
- **DAX (Data Analysis Expressions)**  
- **Power Query (M Language)**  
- **Excel/CSV data sources** (customizable)

## 🚀 Getting Started

1. Clone the repository  
2. Open the `.pbix` file in Power BI Desktop  
3. Connect to your own dataset (or use sample data)  
4. Refresh data and explore interactive reports
